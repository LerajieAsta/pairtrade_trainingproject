# 預先登記：跨期去重（同一配對不得被多個重疊交易期同時持有）

寫定日期：2026-09-30。**本檔在跑之前定稿。**
起因：`dev/repeat_pairs/FINDING.md`——主軸 Top 20 有部位時，25–44% 是同一配對
被 ≥ 2 個重疊交易期同時持有（99% 以上同方向，最多 6 期）。

---

## 一、現況與問題

每 21 日形成一次、交易期 126 日 → 任一時點 6 期並行。引擎逐期獨立模擬、無跨期去重，
配對若連續入選，每一期各配一份資金（equity / (top_n × 6)）、各自交易。
這是 GGR（2006）重疊組合的標準設計，**不是錯誤**，但使：

1. 實際分散度低於帳面的 top_n × 6 個部位；
2. 連續入選者自動拿到多份資金——一種未經設計的隱性加權。

事後描述（FINDING.md，未預先登記）顯示重複入選者控制排名後 +0.13%/期（t = 0.72），
2014 後 −0.03%（t = −0.17）：隱性加權既無顯著加分也無顯著扣分。
本案檢驗**移除這個隱性加權**對組合績效的影響。

## 二、規則（`strategies/dedup.py`、`run_trading.py`）

| 項目 | 規定 |
|:---|:---|
| 範圍 | 同一格（同臂、同 top_n）內的各重疊期之間；不跨臂 |
| 配對的認定 | **不分順序**（A\|B 與 B\|A 為同一條價差；DTW／SDP 臂內兩種順序皆會出現） |
| 約束 | 同一配對同一日最多被一個交易期持有，**不論方向** |
| 已持有者 | 永不被強制平倉 |
| 同日衝突 | 多個期同日要對同一配對新開倉時，**較早開始的期優先**；同期再依形成期排名 |
| 被擋者 | 當日禁止新開倉（entry_gate）；之後若訊號仍在帶外且該配對已無人持有，可再進場 |
| 釋出的資金 | **閒置**，不補給其他候選 |
| 每對資金 | 不變：equity / (top_n × 6) |
| 權益入帳時點 | 與不去重時相同（每期模擬完即入帳；被重新模擬者補差額） |

實作以反覆模擬化解（沿用 `strategies/max_active.py` 的 `resolve_max_active`，k = 1，
每個 (期序, 配對) 為一個單位、同一配對為一組）。結果與「所有期逐日同步模擬、
先平倉再依優先序補位」等價。

**為何不補給其他候選。** 補位會同時改變候選池（引入原本不會交易的配對），
變因不唯一；候選池大小的效果由 `dev/max_active/` 單獨檢驗。

**保留的既有行為（不在本案修正）。** 引擎在每期模擬完即把**整個交易期**的最終損益
計入權益，下一期（21 日後）配置資金時已含前一期未來約 105 日的損益——
這是部位大小上的前視，影響所有既有結果，另案處理。本案兩臂共用同一行為，
故比較不受其影響；但若另案修正該行為，本案須以修正後的引擎重跑。

### 接線驗證（`dev/dedup/pilot.py`，跑網格之前必須全過）

  （`_simulate` 改為可傳入各期的 ctx，預設路徑不得改變）。

## 四、預測（跑前寫下）

1. 名目部署與平均報酬**下降**（部分資金閒置）。
2. 波動與最大回撤**下降**（集中度降低）。
3. Sharpe **變化接近零**：FINDING.md 顯示重複入選者的報酬與新配對無顯著差異，
   移除重複大致等於等比例縮小曝險，而曝險縮放是 Sharpe 中性的（`dev/utilization/FINDING.md`）。
4. Top 20 的變化大於 Top 3（重複持有的絕對數量較多）。

## 五、判準

主要指標：逐格 ΔSharpe = Sharpe(去重) − Sharpe(不去重)，n = 60。
報酬類指標會因曝險下降而機械性變小，**不用來判定**。

**判定「去重有益」須同時滿足：**
1. 60 格中位 ΔSharpe ≥ +0.05；
2. ≥ 40/60 格為正；
3. 後半期（2014-01-02 起）中位 ΔSharpe > 0。

**判定「重複持有有益」（反方向）須同時滿足：**
1. 60 格中位 ΔSharpe ≤ −0.05；
2. ≤ 20/60 格為正；
3. 後半期中位 ΔSharpe < 0。

兩者皆不滿足 → 記為「無差異」，論文只揭露重疊比例，不改主設計。

**判定「去重有益」後須再過的第二階段（跑前寫死，不得省略）：**
去重減少了交易次數；期望值為負時，任何形式的少交易都會避損
（`dev/capital_alloc/RESULTS.md` P2：淘汰規則 13/13 勝等權、0/13 勝同率隨機淘汰）。
故須另跑**同率隨機阻擋**對照——每期隨機擋下與去重相同次數的新進場（不依是否重複），
200 次；去重須在 ≥ 40/60 格勝過其 95 百分位，才稱「去重本身有益」。
此對照需改引擎，只在第一階段通過時才實作。

另外報告（不入判準）：
- 最大回撤、年化波動、平均利用率；
- 被擋的跨期重複進場次數，以及其占原本進場次數的比例；
- 依 top_n 與依排序準則（SSD／DTW／SDP）拆解的 ΔSharpe；
- break-even 成本。
