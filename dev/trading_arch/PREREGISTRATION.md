## 一、問題

`ssd_rolling.normalize_prices()` 把每檔標準化成 $\tilde P_X=(\ln P_X-\mu_X)/\sigma_X$。
spread、$\beta$、ADF、Hurst、半衰期、SSD 排序、交易 z **全部**定義在這個空間：

$$S_t=\tilde P_{A,t}-\beta\tilde P_{B,t},\qquad
\Delta S_t=\frac{r_{A,t}}{\sigma_A}-\beta\frac{r_{B,t}}{\sigma_B}$$

但 `zscore_trading._execute_entry` 以純美元權重建倉（$v_A:v_B=1:|\beta|$），
其損益 $\propto r_A-\beta r_B$。**B 腳錯乘了 $\sigma_B/\sigma_A$。**

實測（`measure_hedge_mismatch.py`，`Grid AGG-SSD-NF` Top20/SL0，5,690 筆）：

| | 現行 |
|:---|---:|
| $\sigma_A/\sigma_B$ 的 p10 / p90 | 0.563 / 1.527 |
| $\lvert\ln(\sigma_A/\sigma_B)\rvert>0.3$ 的配對 | 40.2% |
| 引擎持倉 vs 複製持倉 的毛損益相關 | 0.9216 |
| **符號相反的交易** | **6.34%** |
| $\Delta\lvert z\rvert>1$ 收斂交易：複製組合毛虧損率 | 0.25% |
| $\Delta\lvert z\rvert>1$ 收斂交易：**引擎組合毛虧損率** | **3.08%** |

## 二、這是修正，不是新方法

**判準是「方法本身對不對」。** 不存在任何一種讀法，能讓 $1:|\beta|$ 美元權重
複製路徑 B 的訊號 —— 除非 $\sigma_A=\sigma_B$，而那在 40% 的配對上不成立。
這是實作錯誤，不是曾被選擇過的建模決策（專案內無任何一處記載做過這個選擇）。

**故不新增 `METHOD`、不增加試驗宇宙的 $N$**（維持 method 53 / config 1,392）。
受影響的臂就地重跑並取代舊結果，舊結果視同 `07_附錄B_管線修正記錄` 的前例處理。

> ⚠ **本案的採納與績效方向無關。** 修正後績效變好或變壞都照樣採納 ——
> 若允許「變壞就不採納」，這就退化成一次調參。本節先寫死，是為了讓
> 跑完之後沒有解釋空間。

## 三、確切的改動

$$v_A:v_B=\frac{1}{\sigma_A}:\frac{\beta}{\sigma_B},
\qquad |v_A|+|v_B|=C\ \text{（總名目額不變）}$$

$$w_A=\frac{1}{\sigma_A},\quad w_B=\frac{\beta}{\sigma_B},\quad
v_A=C\frac{|w_A|}{|w_A|+|w_B|},\quad v_B=C\frac{|w_B|}{|w_A|+|w_B|}$$

`entry_z`、`exit_z`、z 的計算、`_compute_spread` **一律不動**。
改的只有「進場當下把 $C$ 拆給兩腳的比例」。

### 適用範圍（逐路徑判定）

| 路徑 | 訊號 | 現行權重 | 判定 |
|:---|:---|:---|:---|
| 路徑 A（`ols_alpha` 非 None，log-price OLS） | $\ln P_A-\alpha-\beta\ln P_B$ | $1:\beta$ | ✅ 已正確，**不動** |
| 路徑 B（`zscore_log`：SSD / DTW / SDP 全系列） | $\tilde P_A-\beta\tilde P_B$ | $1:\beta$ | ❌ 修正 |
| `distance_trading`（`zscore_log`，$\beta\equiv1$） | $\tilde P_A-\tilde P_B$ | $1:1$ | ❌ 修正為 $1/\sigma_A:1/\sigma_B$ |
| `distance_trading`（`ggr_index`） | $P_A/P_{A,0}-P_B/P_{B,0}$ | $1:1$ 於進場價 | ✅ **不動**（GGR 原文即在進場時各投入 \$1） |

`ggr_index` 不動的理由要講清楚：GGR 的 \$1/\$1 本身就不精確複製它自己的
發散度量，那是 GGR 方法的既有性質。本案修的是「本專案的實作與本專案的
訊號不一致」，不是「代 GGR 改論文」。改它會使 GGR 復現臂不再是復現。
