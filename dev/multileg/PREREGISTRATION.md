# 預先註冊：多腿共整合籃子（三腿）

寫定日期：2026-08-26。**本檔在跑之前定稿。** 修改一律以「修訂記錄」附加於末尾。

## 問題

本專案全部策略皆為兩腿。Avellaneda & Lee (2010) 的 eigenportfolio 實為多腿，
但本專案沒有兩腿以外的實作。三腿價差可較兩腿更定態（Johansen 架構）。

## 成本中性（先確立，否則不值得做）

`zscore_trading._execute_entry`：`total_weight = 1 + |β|`、
`v_a = cap/total_weight`、`v_b = cap·|β|/total_weight`，故 $v_a + v_b = \text{cap}$。
手續費按**總名目額**收取。三腿以權重 $(1, \beta_2, \beta_3)$ 平分同一筆 cap，
名目額不變 ⟹ **三腿與兩腿成本相同**。

（此處更正 `dev/ai_proposals.md` 初稿的「1.5 倍成本」——該估計為誤。）

## 建構方式

全窮舉 $\binom{500}{3} \approx 2.07\times 10^7$／期不可行。改為**在既選配對上加第三腿**：

對基準（`Grid (NOGRP-DTW)`）選中的每一對 $(A,B)$，於形成窗內在全體
在指數成分股中搜尋第三腿 $C$，使

$$\tilde P_A = \alpha + \beta_2 \tilde P_B + \beta_3 \tilde P_C + \varepsilon$$

的殘差標準差最小。$C \notin \{A,B\}$，無其他篩選（基礎配對已過 ADF）。

> **此設計回答的是「在既選配對上加第三腿有沒有用」，
> 不是「最佳三元組是否勝過最佳配對」。** 後者需全窮舉，不在本案範圍。
> 若本案為負，全窮舉版本亦不太可能為正（更大的候選集正是方案 A 失敗的機制）。

## 主要風險：過擬合

三腿在形成窗內**必然**擬合得更好（多一個係數），且第三腿是自約 500 個候選中
挑出的。**故門檻一必須完全在樣本外（交易窗）量測**，否則測到的只是過擬合。

另一項先驗顧慮：Kalman 一案實測 $\beta$ 相對漂移中位 **38.4%**。
三腿多一個係數，漂移的自由度更高。

## 門檻

### 門檻一（經濟，樣本外，不需回測）

在**交易窗**內，以形成期係數建構兩種價差，同一進場規則（$|z| > 2$、
$z$ 以形成期 $\mu,\sigma$ 標準化）、同一出場規則（$z$ 穿越 0 或期末），
計算近似經濟捕獲

$$\text{capture} = (|z_{\text{進場}}| - |z_{\text{出場}}|)\times \text{unit}$$

（與 `dev/ml_formation/build.py` 同一算式，unit 換算回分數幅度）。

**三腿的每期平均 capture 須顯著高於兩腿**：逐期配對 $t$ 檢定，$p < 0.05$，效果為正。

附帶報告（不作判準）：形成期殘差標準差比 $\sigma_3/\sigma_2$、
交易窗實現標準差比、收斂率。**前者必然 < 1（過擬合的直接量度），
故不可作為成功證據。**

### 門檻二（經濟，需實跑回測）

僅在門檻一通過時執行。新增交易模組支援三腿，`Grid (NOGRP-DTW)` 15 格全跑，
逐日抽樣 + 循環 block bootstrap（$L$=126、$B$=10,000），
年化報酬差為正且 $p < 0.05$。

## 未過閘的處置

照實記錄為否證。

## 已知限制

1. **非全窮舉**（見上）。
2. 第三腿的選取在形成窗內最佳化，含選擇偏誤；門檻一的樣本外設計即為此而設。
3. 三腿的實際交易需三個標的同時可交易與可放空，本研究不模擬此約束。
