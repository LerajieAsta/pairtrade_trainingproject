# 預先註冊：t+1 執行延遲的受控消融

寫定日期：2026-09-01。**本檔在跑之前定稿。**
起因：`dev/trading_arch/REVIEW.md` §F。

## 一、問題

`_simulate_pair` 的迴圈裡，訊號 $z_i$ 與成交價 $P_i$ 取自**同一根收盤棒**。
`grep 'shift('` 於 `strategies/trading/` 下 0 個結果。

出場尤其樂觀：$z$ 恰好穿越 `exit_z` 的當日即以該日收盤成交。
對均值回歸策略，這是最有利的填單假設——你必須先知道收盤價才算得出 $z$，
再以那個收盤價成交。

**本案問「這個假設值多少錢」。**

## 二、這個消融會動搖什麼、不會動搖什麼（先講，否則會被誤讀）

| 論文主張 | 是否受影響 | 理由 |
|:---|:---|:---|
| 命題 1（ML 分群 vs GICS） | **不受影響** | 兩臂同樣延遲，相對比較仍公平 |
| 命題 2（DRL/監督學習 vs 靜態門檻） | **不受影響** | 同上 |
| 2.4 停損一律有害 | **不受影響** | 同上 |

**結論先寫死：本消融威脅的是絕對績效主張，不是本研究的相對比較結論。**
若不先講清楚，一個負面結果會被誤讀為「整篇論文垮了」。

## 三、與文獻的關係（2026-09-03 查證完畢）

原文已核對：`Reference/In/2006-Pairs Trading Performance of a Relative-Value Arbitrage Rule.pdf`
（Gatev, Goetzmann & Rouwenhorst 2006, *RFS* 19(3):797–827）。

**我的印象在「有沒有」與「方向」上正確，在「地位」上錯了——
那不是附在主結果後面的穩健性檢定，那就是主結果。**

### 原文的數字（Table 1，月超額報酬，fully invested）

| 組合 | 不等待 | 等一日 | 差 |
|:---|---:|---:|---:|
| Top 5 | 1.308% | 0.745% | −0.563pp（−43%） |
| **Top 20** | **1.436%** | **0.895%** | **−0.541pp（−38%）** |
| 101–120 | 1.081% | 0.795% | −0.286pp（−26%） |
| All（平均 2057 對） | 1.104% | 0.715% | −0.389pp（−35%） |

### 三件必須一起講的事

**1. 摘要的「年化約 11%」是等待版的數字。**
$0.895\% \times 12 = 10.7\%$。不等待版是 $1.436\% \times 12 = 17.2\%$。
p. 811 明講：「As in Table 1, the pairs are traded with a one-day delay before
opening **and closing** a position to minimize the effect of the bid–ask bounce.」
Table 3 以後全部是延遲版。**GGR 的主規格是 t+1，同棒成交只出現在 Table 1 的對照欄。**

**2. GGR 把這 −0.541pp 解讀成成本估計，不是解讀成策略變差。**
p. 809 §3.3 的推導：若第一次穿越時贏家成交在 ask、輸家在 bid，隔日價格在
bid/ask 等機率，則延遲一日平均吃掉半個價差和；第二次穿越再吃半個。
六個月掉 324 bp ÷ 平均 2 次往返 = 每次往返 162 bp，即**有效價差 81 bp**
（全對組合 70 bp）。延遲是他們**用來取代成本模型的工具**。

**3. 因此原文的量級不可與本消融並列。**
GGR 的 Table 1 沒有外加成本模型，延遲**就是**成本代理；
我們則另外扣單邊 0.29%（Do & Faff 2012）。兩者相加是重複計價。
本消融量的是**在成本已另計之後，同棒成交還多賺了多少**——
一個 GGR 沒有量過、也不需要量的東西。

> 方向可引用，量級不可引用。本檔以下不出現 GGR 的任何百分比作為預期值。

### 對本研究的兩個直接後果

**(a) `dev/ggr/SPEC.md` 的 16 項對照表缺「執行時點」這一列——而且缺得比原先以為的嚴重。**
原先的說法是「漏掉原文自己強調的一項」。實際上：我們的 GGR 臂用同棒成交，
對應的是原文 Table 1 的**對照欄**，不是原文的主規格。
該表 16 項標了 14 個 ✓，但這一項連列都沒列。已補為第 17 項。

**(b) 本消融的「乙」條件在 GGR 框架下沒有對應物。**
GGR 只做 open 與 close 一起延遲（即本檔的「丙」）。
拆成進場／出場分離是本消融新增的，原文沒有這個切分——
故 §五對出場方向拒絕預測，不能拿原文來背書，也不會被原文推翻。

## 四、設計

### 語意（精確定義，避免事後解釋）

延遲 $L$ 根 bar 的意思是：**決策用 bar $i-L$ 的資訊，成交用 bar $i$ 的收盤價。**

| 元素 | 延遲後的取值 |
|:---|:---|
| 進場條件 `_entry_triggered` | $z_{i-L}$ |
| 出場條件 `exit_z` 穿越 | $z_{i-L}$ |
| z 停損 `dynamic_stop_z` | $z_{i-L}$ |
| 資本停損 `stop_loss_pct` | 以 bar $i-L$ 的價格算未實現損益 |
| 時間停損 `max_holding_days` | 同出場範疇 |
| **成交價（進場與出場皆是）** | $P_i$ |
| 逐日 mark-to-market 的未實現損益 | $P_i$（可觀測，不需延遲） |
| **期末強平** | **不延遲**——機械事件，非訊號決策 |
| 前 $L$ 根 bar | 不做任何決策 |

### 三個條件，不是一個

進場與出場的延遲**方向未必相同**（見 §五），故必須分離：

| 條件 | `exec_lag_scope` | 延遲範圍 |
|:---|:---|:---|
| 基準 | `none`（$L=0$） | 無 |
| 甲 | `entry` | 只延遲進場 |
| 乙 | `exit` | 只延遲出場（含三種停損） |
| 丙 | `both` | 兩者 |

$L = 1$ 固定，不掃描。

### 範圍

| 臂 | 選它的理由 |
|:---|:---|
| `Grid (NOGRP-SDP)` | 四條主力之一，與 `dev/stops` 同組可直接對照 |
| `Grid (NOGRP-SSD)` | 同上 |
| `Grid (GICS-SSD)` | 同上 |
| `Grid (NOGRP-DTW)` | 同上 |
| `Grid (GICS-SSD-FW504)` | 現行 Sharpe 最高（0.634），絕對主張的承重點 |
| `Grid (GGR)` | 復現臂；GGR 原文自己做過此檢定 |

6 臂 × 15 格 × 3 條件 = **270 個配置**（`GGR` 為 Top20 單格，實際略少）。

**不跑全網格。** 本案要的是機制與量級，不是每一格的數字；
全網格重跑的成本（約兩日）在此不成比例。

## 五、可否證的預測（跑之前寫死）

| # | 預測 | 判準 | 若不成立代表 |
|--:|:---|:---|:---|
| P1 | $L=0$ 與現行結果**逐位元相同** | 全欄 diff = 0 | 改動洩漏到基準路徑 |
| P2 | **甲（只延遲進場）使報酬下降** | 年化報酬差為負，六臂中至少五臂同號 | 我對進場延遲的機制理解錯了 |
| P3 | **乙（只延遲出場）方向不預測** | —— | 見下 |
| P4 | 丙 ≈ 甲 + 乙（近似可加） | $\lvert$丙 − (甲+乙)$\rvert$ < 0.5 × max($\lvert$甲$\rvert$, $\lvert$乙$\rvert$) | 存在我未預期的交互 |
| P5 | 進場次數變動 < 5% | 各臂 `Entries` 相對差 | $\lvert z\rvert>2$ 的持續性不如預期 |

### P2 為何預測下降

$\lvert z\rvert > 2$ 觸發時，序列處於偏離態；均值回歸序列的次日期望值朝均值移動。
延遲一日進場 → 進場時的 $\lvert z\rvert$ 期望上較小 → 可捕獲的 $z$ 較少。
**這是單向的，故敢預測。**

### P3 為何不預測方向——這才是本實驗的未知數

出場觸發於 $z$ **首次**穿越 `exit_z`，這是首達事件（first passage），
不是隨機時點。首達之後：

- 若序列帶著回歸動能續行穿越（$z$ 越過 0 到另一側），**延遲出場反而多賺**
- 若在 0 附近震盪，延遲出場的損益是對稱雜訊，**期望為零**
- 若立刻反彈回原方向，**延遲出場少賺**

三種力量方向不同，且相對強弱取決於價差在 0 附近的局部動態——
**我沒有先驗可以判斷哪個佔優。**

依 CONTEXT.md 的 Proxy 規則，這也不能用 `capture_frac` 估：
延遲改變進場頻率與部位釋出時點，代理算不出組合層效果。**必須實跑。**

## 六、判準：什麼結果會改寫論文

本案**不是**「過閘就採用」的提案——t+1 不是要不要採用的選項，
而是要不要**揭露**的事實。故無單一門檻，改為三條事先寫死的敘述規則：

1. **若丙條件下四條主力臂的 break-even 往返成本全部低於 0.58%**
   → 「扣成本後仍為正」的敘述必須撤回，改寫為「在同棒成交假設下為正，
   在 t+1 執行下不成立」。這是論文層級的修改。

2. **若丙的年化報酬下降幅度 < 0.2 pp 且 break-even 仍高於 0.58%**
   → 以一句話與一張附表揭露，主表維持同棒口徑（與文獻可比）。

3. **介於兩者之間** → 主表改為並列兩個口徑。

**三種情形都要寫進論文。方向不影響是否揭露。**

## 七、主口徑仍為同棒，理由

t+1 跑完之後，論文主表**仍以同棒為主口徑**（除非觸發規則 1），因為：

- 本研究的核心是**受控比較**（AI 各層 vs 對照），同棒是所有既有結果的共同基準
- 文獻（GGR、Do & Faff、Han et al.）的可比數字多為同棒
- 換主口徑等於把 1,152 格全部重跑，且會使既有的三份預先註冊結果失去對照基準

**但這個選擇本身必須在論文中明說，並附 t+1 的數字。**
「因為可比性所以用較樂觀的假設」是可辯護的；不講才不是。

## 八、試驗宇宙

三個條件皆帶檔名後綴（`_LAG1E` / `_LAG1X` / `_LAG1B`），
為**同一 METHOD 下的配置變體**，故 method $N$ 維持 53；config $N$ 增加 270。

> 可爭論之處：本案報告全部條件、不從中挑選，嚴格說不構成「搜尋」，
> 不必計入 $N$。但既有的 `_DSZ` / `_MHD` 變體皆已計入，
> **依循先例並保持較大的 $N$ 只會使 DSR 門檻更嚴，是保守的一側。**
