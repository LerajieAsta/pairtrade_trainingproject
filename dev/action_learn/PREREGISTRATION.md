# 預先註冊：以監督回歸學習逐對進出場門檻

寫定日期：2026-08-26。**本檔在跑之前定稿。**

## 問題

現行交易端對所有配對用同一組 $(\text{entry\_z}, \text{exit\_z}) = (2.0, 0.0)$。
`exit_scan.parquet` 提供 20 個動作（entry_z ∈ {1.5,2.0,2.5,3.0} × exit_z ∈ {0,.25,.5,.75,1.0}）
的**完整反事實捕獲**，故「該用哪個門檻」是可監督學習的。

## 為何不是重做 DRL

論文 2.3.3 已載明：**動作報酬可完整回算，故此為全資訊監督回歸而非部分回饋的強化學習。**
既有 DRL 的診斷顯示其輸出近乎常數（門檻中位 2.11–2.33，
`Spearman(門檻, 名次) ≈ 0`），即塌陷至邊際平均解。
**本案不調 DRL 的超參數、不換 RL 演算法，而是改用監督範式。**

## 天花板與訊號（跑之前已量測，屬設計依據）

- 完美預知逐對動作 vs 最佳常數動作：**6.5 倍**
  （Top5：常數 `e2.5_x0.0` +0.007881，完美 +0.051359）
- 最佳 entry_z 的分布分散：1.5/2.0/2.5/3.0 佔 14.8/14.9/23.7/46.6%
- 逐期 `Spearman(rho_seg_std, 最佳 entry_z)` = **+0.1007 ± 0.0299（t = 3.37）**，
  `rho_seg_range` = +0.0970（t = 3.28）——訊號弱但顯著，且與「不穩定關係需要更高門檻」一致

## 設計

| 項目 | 設定 |
|:---|:---|
| 特徵 | `train.parquet` 的 45 欄（梯子已建，不新增） |
| 目標 | 20 個動作各自的 `cap_*`（多輸出回歸），選預測值最大者 |
| 模型 | 梯度提升樹（與梯子 M1/M2 同族），超參數沿用梯子設定 |
| 訓練母體 | ADF 通過且標籤有效的**全候選池** |
| 評估母體 | **SSD top-5**（常規做法，非 top-1） |
| 前推 | 暖身 36 期／擴張窗／每 12 期重訓／6 期隔離帶（與梯子相同） |

## 基準（必須也是樣本外）

**不可用全樣本最佳常數（`e2.5_x0.0`）當基準**——那本身用了未來資訊。
基準為「**擴張窗最佳常數**」：在每一期，取截至前一期為止平均捕獲最高的常數動作。

附帶報告：現行設定 `e2.0_x0.0`（固定），供對照。

## 門檻

**單一門檻**：模型選取的動作，其每期平均 `capture_frac`
須顯著高於擴張窗最佳常數——逐期配對 $t$ 檢定，$p < 0.05$，效果為正。

未過即停：不回測、不新增策略、試驗宇宙不變（method $N$ = 53）。

## 過閘後

以模型的逐對門檻實跑回測（`Grid (NOGRP-SDP)` 與 `Grid (NOGRP-SSD)` 的 Top5/SL0，
兩者為 `top_n ≥ 5` 中年化最高者），依論文交易層口徑檢定。$N$ 隨之增加。

## 已知限制

1. `capture_frac` 為近似經濟捕獲，非回測損益。本案 `top_n`、`trading_window` 不變，
   故本專案兩次代理失準的機制（算不出組合波動）不適用；
   但仍**只保證報酬率方向**，Sharpe 須實跑。
2. 20 個動作的反事實表以**第一輪**交易計算，而引擎會再進場
   （實測每配對期約 2.1 次）。故代理低估多輪的影響，方向不明。
3. 訊號量級小（$\rho \approx 0.10$）。天花板 6.5 倍雖大，
   **可捕獲的比例未知，這正是本案要測的**。
