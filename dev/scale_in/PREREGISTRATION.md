# 預先登記：依偏離程度分層加碼（交易端）

寫定日期：2026-10-21。**本檔在跑之前定稿。**

---

## 一、問題與動機

現行 Z-Score 交易端是二元決策：$|z| > 2$ 即以整份 `capital_per_pair` 進場，之後不論價差再偏離多少，部位不變。
跨期去重研究（`dev/dedup/RESULTS.md`）發現，六個重疊交易期同時持有同一配對時，後進場的那份往往是在**價差更偏離時**
進場，且貢獻了大部分的去重損失——重疊組合「意外地」做到了分批加碼。
文獻上 Mudchanatongsuk 等 (2008) 的最適部位與偏離程度成正比；實務上的分層進場（scale-in）也是同一想法。

本案檢驗：**把「偏離越大、部位越大」寫成明確規則，在單一配對最大名目額不變的前提下，是否優於二元進場？**

> 與 `dev/IMPASSE.md` 障礙四（不加槓桿的曝險等比例縮放對 Sharpe 中性）的關係：本案**不是**等比例縮放——
> 部位大小依當下的 $|z|$ 而定，是條件式配置。若加碼層極少觸發，本案退化為「半份部位的現行策略」，
> Sharpe 應與現行相同（障礙四），ΔSharpe ≈ 0；ΔSharpe 顯著異於 0 才代表「在更偏離時投入」本身有價值或有害。

## 二、規則（寫死）

參數：`scale_in_z = 3.0`、`scale_in_frac = 0.5`（預設 `scale_in_z = 0` 為停用，既有行為逐位元不變）。

1. **第一層**：$|z| > 2$（現行門檻）時進場，名目額為 `scale_in_frac × capital_per_pair`（半份）。
   若進場當日已 $|z| > 3$，直接以整份進場（兩層同時）。
2. **第二層**：持有第一層、且當日未觸發任何出場或停損時，若 $z$ 與部位同方向且 $|z| > 3$，以當日收盤價加碼另一半，
   兩腳權重與第一層相同公式（signal 避險，當日 β）。每筆交易最多加碼一次。
3. **出場**：與現行相同，$z$ 回到 0 即兩層一起平倉；資本停損仍以 `capital_per_pair`（整份）為分母、以兩層合計的交易損益判定；
   期末強制平倉不變。平倉後可再次依第 1 點進場。
4. **成本**：每層各付進場摩擦（0.29% × 該層名目額），出場以合計部位付摩擦。持倉成本以加權平均進場價記帳。

**單一配對的最大名目額與現行完全相同**（整份），不增加槓桿；平均曝險低於現行。

## 四、判準（跑前寫死）

主要指標：逐組 ΔSharpe = (15 格 Sharpe_Raw 平均)_分層 − (15 格 Sharpe_Raw 平均)_現行，n = 8。
以 Sharpe 而非損益差為主，因分層的平均曝險較低，損益差會機械性偏負（障礙四）。

**判定「分層加碼較佳」須同時滿足：**
1. ≥ 6/8 組 ΔSharpe > 0；
2. 8 組中位 ΔSharpe ≥ +0.05；
3. 後半期（2014-01-02 起）中位 ΔSharpe > 0。

**判定「現行較佳」須同時滿足：** ≤ 2/8 為正、中位 ≤ −0.05、後半期中位 < 0。其餘 → 無差異。

另報（不入判準）：15 格等權逐日損益差分（4.3 同程序，8 組 BH）；**組合市場 β**；加碼層觸發率；
加碼層與第一層各自的平均交易損益（以加碼日價格拆分）；平均曝險；停損次數；rf 超額。

**績效不佳的處置**（同 2026-10-21 使用者指示）：若「分層加碼較佳」不成立，`scale_in.db` 只留摘要、刪除逐日紀錄
（拆分分析於刪除前完成）。

## 六、接線驗證（跑網格前必須全過）

- **V1**：`scale_in_z = 0`（預設）時，GICS-SSD 與不分組-DTW 的 Top1/SL0 與 result.db 逐位元相同。
- **V2**：`scale_in_z = 1e9`（加碼層永不觸發）、`scale_in_frac = 0.5`、停損 0：逐日損益（未捨入）恰為現行的 0.5 倍（相對差 < 1e-9）。
- **V3**：以獨立程式（逐日迴圈，不呼叫引擎）重算數個含加碼事件的配對期，逐日累積損益與引擎一致（< 1e-6 美元）。
- **V4**：`scale_in_frac = 1.0` 時與現行逐位元相同（第一層即整份、加碼層名目額為 0）；並回報 V3 那一格的加碼觸發率（須介於 0 與 1）。

## 附記（2026-10-21，接線驗證之後補記；規則與判準未改動）

- **V1 通過**：`scale_in_z = 0` 時 GICS-SSD、不分組-DTW 的 Top1/SL0 摘要（Sharpe、期末權益、進場數、勝率、MDD、利用率）與 result.db 逐位元相同。
- **V2 通過**：40 個 GICS-SSD 配對期，加碼層永不觸發時逐日損益與 0.5 × 現行的最大差 5.0e-05（即 4 位四捨五入的誤差界），期末亦同。
- **V3 通過**：36 個含第二層的配對期，獨立逐日迴圈重算的累積損益與引擎最大差 5.0e-05。
  （初版 V3 失敗是驗證程式本身把做空價差時 A 腳的方向寫反，引擎未改動。）
- **V4 通過**：`scale_in_frac = 1.0` 時摘要與 result.db 逐位元相同；有進場的配對期中 92.3%（36/39）出現第二層
  （含進場當日即 |z| > 3 而整份進場者）——第二層並非罕見事件，本案不會退化為單純的半份部位。
- 已知限制：`Avg_Utilization` 以 Position ≠ 0 計算，只持第一層（半份）時仍計為滿額，故分層臂的利用率被高估；
  評估以 `SI_Tier` 另算實際平均曝險。
