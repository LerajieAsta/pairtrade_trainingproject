# Break-even 名目額的兩處錯誤（2026-08-26）

`analysis/regime_cost_dsr_eval.py` 的往返 break-even 計算在兩處低估。
`results/analysis/breakeven_dsr.csv` 為論文第四章引用的表，故已修正並重跑。

## 錯誤一：資金基礎

```python
cap_per_pair = INITIAL_CAPITAL / top_n        # 舊
```

實際配置為 `portfolio_manager.py:84`：

```python
capital_per_pair = current_equity / max_pairs      # max_pairs = top_n × 並行期數
```

並行期數 = `trading_window / rolling_step` = 126/21 = **6**
（`run_trading.py:245` 逐策略推導）。

舊算法**漏掉 ×6**（名目額高估 6 倍），且以初始資金取代逐日權益
（權益自 \$10,000 成長至 \$22,350，後期被系統性低估）。

## 錯誤二：事件數

```python
sigma_notional = cap_per_pair * (entries + exits)   # 舊
```

實測 **`Entries = Exits + Stop_Losses + Forced_Closes`**
（SL0 列 385/912 精確成立；SL>0 時三類齊全亦成立）。
每次進場恰對應一次平倉，故費用事件為 **2 × Entries**。

舊算法用 `Entries + Exits`，**漏計停損與強制平倉的出場費**：
Top1/SL0 少算 17.3%、Top20/SL0 少算 23.2%。

## 淨效果

兩者方向相反，但資金基礎的 6 倍主導。10 條主力臂全部上升 0.20–0.40 個百分點：

| 策略 | 舊 BE% | **新 BE%** | 舊餘裕 | **新餘裕** |
|:---|---:|---:|---:|---:|
| **Grid (NOGRP-DTW)** | 0.820 | **1.219** | +0.240 | **+0.639** |
| Grid (AGG-SSD-NF-NOSEC) | 0.744 | 1.074 | +0.164 | +0.494 |
| Grid (NOGRP-SSD) | 0.724 | 1.034 | +0.144 | +0.454 |
| Grid (NOGRP-SDP) | 0.680 | 0.935 | +0.100 | +0.355 |
| Grid (GICS-SSD) | 0.682 | 0.877 | +0.102 | +0.297 |

**旗艦策略的成本承受力是原報告的 2.6 倍。**

### 淨利為負者方向相反（正確）

$\text{BE} = 2\left(\text{fee} + \dfrac{p_{\text{net}}}{\text{notional}}\right)$

$p_{\text{net}} > 0$ 時修小名目額使 BE **上升**；$p_{\text{net}} < 0$ 時使 BE **下降**。

| | 舊算 | **新算** | 對成本 0.580% |
|:---|---:|---:|---:|
| GGR-SSD（$p_{\text{net}}<0$） | 0.552 | **0.411** | **−0.169 pp**（舊：−0.037） |

`dev/ggr/RESULTS.md` 的「只差 0.037 個百分點」須改為 **0.169**——方向不變，幅度差 4.6 倍。

## 延伸：零成本情境

費用逐日加回後：

| 策略 | 實際 Sharpe | 零成本 Sharpe | DSR 顯著所需（N=44） |
|:---|---:|---:|---:|
| NOGRP-DTW Top1 | 0.468 | **0.763** | 0.657 |
| GGR Top20 | −0.337 | **0.809** | 0.657 |

**兩者的零成本 Sharpe 皆超過門檻。** 零成本不可交易，
但這量化了一件事：**「無一顯著」的結論對 0.29% 這個成本假設極度敏感**，
而該假設源自 Do & Faff (2012) 對更早期美股的估計。
修正後的 break-even 1.219% 顯示旗艦策略的頭寸遠比原報告寬。

程式見 `zero_cost_sharpe.py`。
