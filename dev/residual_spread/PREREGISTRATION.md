# 預先登記：以殘差報酬累積定義價差（交易端）

寫定日期：2026-10-20。**本檔在跑之前定稿。**

---

## 一、問題

現行所有主軸策略的價差以**形成期標準化的對數股價**定義：
$\tilde P_X(t) = (\ln P_X(t) - \mu_X)/\sigma_X$，$S(t) = \tilde P_A(t) - \beta\,\tilde P_B(t)$，
$\beta$ 為形成期在標準化空間的 OLS 斜率；交易期沿用形成期的 $\mu, \sigma, \beta$ 與價差均值、標準差。

本案以 Avellaneda & Lee（2010）的**殘差報酬累積**取代之，檢驗價差的定義方式是否影響績效：

$$r_X(t) = \ln P_X(t) - \ln P_X(t-1),\qquad r_A = \alpha + \beta\, r_B + \varepsilon\ \ (\text{形成期 OLS})$$
$$X(t) = \sum_{s \le t} \big(r_A(s) - \alpha - \beta\, r_B(s)\big),\qquad Z(t) = \frac{X(t) - \bar X_{\text{form}}}{\operatorname{sd}(X_{\text{form}})}$$

累加自形成期首日，延續至交易期；$\alpha, \beta, \bar X_{\text{form}}, \operatorname{sd}(X_{\text{form}})$ 皆只用形成期資料估計，
交易期不重估（與現行 `zscore_window = 0` 相同）。

與現行定義的差異：(1) $\beta$ 改由**日報酬**迴歸估計，而非價格水準；(2) 扣除每日漂移 $\alpha$；
(3) 不以 $\sigma_X$ 標準化各腳（價差直接在對數報酬尺度上）。

## 二、範圍與唯一變因

| 項目 | 規定 |
|:---|:---|
| 臂 | 主軸 15 支 `Grid {NOGRP,GICS,HDB,AGG,KM}-{SSD,DTW,SDP}`（Z-Score，252 日形成期） |
| 網格 | 與主軸相同：Top {1, 3, 5, 10, 20} × 停損 {0%, 5%, 15%} = 每臂 15 格，共 **225 格** |
| 形成期配對 | 沿用既有（**不重跑形成期**，配對集合完全相同） |
| 交易端 | `zscore_trading`，新增參數 `spread_mode="residual_return"`；其餘參數逐字沿用 |
| 部位 | $\Delta X = r_A - \beta r_B$，故兩腳金額比 $1 : \lvert\beta\rvert$（$\beta$ 為報酬迴歸值），總名目額不變 |
| 進出場、停損、資金配置 | 不變（進場 $\lvert Z\rvert > 2.0$、出場穿越 0、期末強制平倉） |
| 寫入 | `results/residual_spread.db`；對照組為 result.db 既有的同格（不重跑） |

**$\beta \le 0$ 的配對**：現行引擎以 $\lvert\beta\rvert$ 分配、固定「多 A 空 B／空 A 多 B」，本案沿用同一處理，
不另行排除（排除會改變配對集合，變因不唯一）。跑完後報告 $\beta_{\text{ret}} \le 0$ 的配對期比例。

**形成期價格的截斷**：以 `full_price_df.loc[形成期起, 交易期起)` 取價。全期回測自 2000-01 起，
第一期形成期起點即資料起點，不會被截斷；仍於實作中檢查可用報酬數，少於 60 筆的配對期不交易並計數報告。

## 三、判準（跑前寫死）

主要指標：逐臂 ΔSharpe = Sharpe(殘差報酬價差) − Sharpe(現行價差)，以**15 格各自 Sharpe 的平均**
（論文 5.1.1 的衡量方式）計算，n = 15 臂。

**判定「殘差報酬價差較佳」須同時滿足：**
1. 15 臂中位 ΔSharpe ≥ +0.05；
2. ≥ 10/15 臂為正；
3. 後半期（2014-01-02 起）15 臂中位 ΔSharpe > 0。

**判定「現行價差較佳」須同時滿足：** 中位 ≤ −0.05、≤ 5/15 臂為正、後半期中位 < 0。
兩者皆不滿足 → 「無差異」。

另報（不入判準）：
- 15 格等權逐日差分的年化 Δ 與循環區塊自助法（L = 126、10,000 次）、15 臂 BH 校正（與 4.3 同程序）；
- 換手率（每期每對進場次數）、平均持有日數、出場方式分解（正常收斂／停損／期末強制平倉）；
- $\beta_{\text{ret}}$ 與 $\beta_{\text{level}}$ 的分布與相關、$\beta_{\text{ret}} \le 0$ 的比例、形成期報酬不足而未交易的配對期數；
- break-even 成本。

**若判定為「殘差報酬價差較佳」**：不直接取代主設計；須先對 DL-THR 臂與 504 形成期重跑確認，另行預先登記。
