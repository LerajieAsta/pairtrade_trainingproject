## 機制（事後分析，未預先登記）：殘差報酬版不是市場中性的

**$\beta_{\text{ret}}$ 系統性地低於 $\beta_{\text{level}}$**：各臂中位 $\beta_{\text{ret}}$ 0.61–0.78，$\beta_{\text{level}}$ 0.98 左右。
日報酬含大量雜訊與非同步交易，迴歸斜率受「變數有誤差」的衰減偏誤而偏向 0。部位依 $1:|\beta_{\text{ret}}|$ 配置，
B 腳避險不足，組合留下淨市場曝險。

抽四臂，以 15 格等權逐日報酬對成分股等權市場報酬迴歸：

| 臂 | 市場 β（現行 → 殘差報酬） | 等權 Sharpe | **扣市場曝險後** Sharpe |
|:---|:---|:---|:---|
| GICS-SSD | +0.002 → **+0.042** | +0.136 → +0.384 | +0.124 → +0.177 |
| HDB-SSD | −0.003 → **+0.040** | −0.085 → +0.405 | −0.068 → +0.207 |
| NOGRP-SSD | −0.005 → **+0.045** | +0.216 → +0.439 | +0.238 → +0.252 |
| KM-SSD | +0.006 → **+0.036** | −0.211 → +0.042 | −0.256 → −0.224 |

- 現行價差的組合**市場 β ≈ 0**；殘差報酬版穩定為 **+0.04**。
- 扣除市場曝險後，四臂中三臂的改善大多消失（NOGRP-SSD +0.22 → +0.01、GICS-SSD +0.25 → +0.05、
  KM-SSD +0.25 → +0.03）；只有 HDB-SSD 仍保留明顯改善（+0.28）。
- **後半期改善更大**也與此一致：2014 年後為長期多頭，正 β 在此段收益最多。

> 為何淨曝險為正而非正負相抵：本案未拆解（可能來源為進場方向的不對稱、或形成期漂移 α 外推所致的方向偏好）。
> 四臂之外的十一臂未做此檢查；結論以這四臂為據。

## 結論

1. 依預先登記字面，「殘差報酬價差較佳」成立（中位 +0.178、14/15、後半期 +0.336）。
2. 但改善的主因是**報酬迴歸 β 的衰減偏誤造成避險不足**，組合帶有約 +0.04 的市場 β；扣除後多數臂的改善消失。
   這與 `dev/utilization/FINDING.md`「放大曝險是純槓桿」同類：表面的 Sharpe 改善是承擔了不同的風險，不是更好的訊號。
3. **不建議以此更改主設計**，也不進入預先登記所稱的 DL-THR／504 確認重跑。
4. 若要隔離「價差定義」本身的效果，下一步應保持市場中性——例如以殘差報酬累積產生訊號、但部位仍以
   $\beta_{\text{level}}$（或以市場 β 中性化）配置——須另寫預先登記。
5. 試驗宇宙（2026-10-21 已更新 `TRIAL_CENSUS`）：225 格為既有 15 個 METHOD 下的配置，method N 維持 75、
   config 2,325 → 2,550（庫外 135 → 360）；var_sr（method）0.00019819 → 0.00019537，**SR₀ 0.543 → 0.539**。
   55 條 Z-Score 策略仍無一通過 0.95（最高 GICS-SSD-FW504 0.695）；`_RR` 格不在正式 DSR 表的候選內，
