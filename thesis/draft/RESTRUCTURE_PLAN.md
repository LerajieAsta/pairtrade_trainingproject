日期：2026-09-08。本檔是**給指導教授看的改題說明**，也是後續改寫的施工圖。

## 一、為什麼要改

**不是主題太大，是主題壓錯了重量。**

現行題目「配對交易改良的分層歸因」把貢獻掛在**統計推論**上——
§5.2.1 的五項方法論貢獻（偽重複、信賴區間解讀、單變因架構保證、
限制的量化揭露、產業資訊管道）全部是統計與實驗設計。

但本研究的作者是資訊管理背景，口試委員亦為資訊管理背景。
把貢獻宣稱放在統計推論上，等於**把辯護戰場設在最弱的一塊、
而且不是委員的專業領域**。同時，作者實際產出且守得住的東西
——四層中性組裝器、可重跑的分析管線、14 個有記錄的實作缺陷、
11 個預先註冊實驗——目前全被放在附錄。

另有一項結構性困難：現行論文的**主結果是 null**
（分組層 0/9、組合系統 0/3）。宣稱 null 必須證明自己有檢定力，
而 §4.5 已誠實承認做不到——形成期層的最小可偵測效果 1.14pp、
對 0.3pp 真實效果的檢定力僅 11%。**這條路在方法上是死的。**

不需要證明「我有能力偵測到不存在的東西」。這一項就消掉了整個 §4.5。

## 五、仍然必須學會的統計

改題**不會把統計降到零**，但會把它降到兩個概念：

| 概念 | 為何非學不可 | 現有說明位置 |
| :--- | :--- | :--- |
| 循環 block bootstrap | 它產出主結果的 $p$ 與信賴區間 | §3.5.2（含為何不用 HAC、為何 $L$=126） |
| BH-FDR 校正 | 五個配對底是同一項檢定，必須一起校正 | §3.5.4 |

其餘存活下來的**全部是資訊本科概念**，不需另學：

- 置換檢定（三項替代解釋）＝ 隨機洗牌基準，本質是 Monte Carlo
- 五輪重訓變異 ＝ seed variance，ML 常識
- walk-forward ＝ train/test 切分
- 等權口徑 ＝ 避免 best-of-N 的選擇偏誤，等同不在測試集上調參

## 六、三項必須誠實面對的風險

1. **主結果在門檻上很脆。** K-means 的 BH 校正後 $p$ = 0.0495 通過、
   GICS-SSD 的 0.0504 未通過，相差 0.0009。
   被問「到底顯不顯著」時，正確答案是：
   *效果量 +0.239~+0.798pp、五個配對底有四個信賴區間下界為正；
   二分法不是這裡該用的框架。*
   這句話必須真的理解才講得出來。

2. **絕對績效不顯著、DSR 全數未過。** 論文的訊息是
   「相對於固定門檻有改善，但不足以交易」——有層次，不是
   「我做出一個會賺錢的策略」。第五章必須把這條界線畫清楚。

3. **機制證據與統計顯著兩份清單不重合。**
   三項機械性解釋全排除的是 GICS-SSD／HDBSCAN／GICS-SDP，
   BH 校正通過的是 HDBSCAN／GICS-SDP／K-means，
   **交集只有 HDBSCAN 與 GICS-SDP**。不可含混地說「GICS 兩底」。
