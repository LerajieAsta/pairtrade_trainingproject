## 一、為什麼要改

**不是主題太大，是主題壓錯了重量。**

現行題目「配對交易改良的分層歸因」把貢獻掛在**統計推論**上——
§5.2.1 的五項方法論貢獻（偽重複、信賴區間解讀、單變因架構保證、
限制的量化揭露、產業資訊管道）全部是統計與實驗設計。

但本研究的作者是資訊管理背景，口試委員亦為資訊管理背景。
把貢獻宣稱放在統計推論上，等於**把辯護戰場設在最弱的一塊、
而且不是委員的專業領域**。同時，作者實際產出且守得住的東西
——四層中性組裝器、可重跑的分析管線、14 個有記錄的實作缺陷、
11 個預先註冊實驗——目前全被放在附錄。

另有一項結構性困難：現行論文的**主結果是 null**
（分組層 0/9、組合系統 0/3）。宣稱 null 必須證明自己有檢定力，
而 §4.5 已誠實承認做不到——形成期層的最小可偵測效果 1.14pp、
對 0.3pp 真實效果的檢定力僅 11%。**這條路在方法上是死的。**

#### 第二段：逐對學門檻輸給最佳常數（正式證據）★

`dev/action_learn/`（2026-08-26，**預先註冊、跑前定稿**，判決「未過閘」）：

| | 每期平均 `capture_frac` |
| :--- | ---: |
| 逐對學門檻（30 維特徵 × 20 動作） | +0.005510 |
| **擴張窗最佳常數**（基準） | **+0.010397** |
| 差 | **−0.004887**（配對 $t$，$p$ = 0.0004） |
| 現行 `e2.0_x0.0`（附帶） | +0.006932 |

樣本：91,775 列、295 期、30 維特徵、20 動作；暖身 36 期／擴張窗／
每 12 期重訓／6 期隔離帶；訓練用全候選池、評估用 SSD top-5。

**機制（這是論文要講的重點，也是資訊本科的語言）**：
設計依據的訊號為逐期 `Spearman(rho_seg_std, 最佳 entry_z)` = **+0.1007**
（$t$ = 3.37）。$\rho \approx 0.10$ 屬弱訊號，而選取方式是**對 20 個獨立
回歸的預測值取 argmax**——弱訊號下 argmax 系統性偏向**預測誤差最大**的
輸出，選取本身引入的雜訊超過訊號。這是**多輸出選取在低訊噪比下的典型病理**。

**為何這一段比第一段好用**：

- 可重現：預先註冊、有腳本、有輸出，不依賴已刪除的回測列
- 判準寫在跑之前，不是事後解釋
- 機制可直接說明，不需要財金理論也不需要重抽分布
- 它與既有 DRL 的失敗是**同一件事的兩面**：DRL 塌陷成近常數
  （門檻中位 2.19–2.37、`Spearman(門檻, 名次)` ≈ 0），
  監督回歸則比常數更差——**雜訊太大時，最安全的預測就是常數**

#### 第三段：v4 動作空間的實測（正面結果）

即 §4.2：SKIP ＋ 8 組 (entry_z, exit_z) 門檻的動作空間，
相對固定門檻 Z-Score 在五個配對來源上方向全正、BH 校正後 3/5 顯著。

### 三段合起來要講的一句話

> **門檻選擇的增益來自動作空間的設計，不來自逐對辨識能力。**
>
> 自由持倉的動作空間讓模型對日級噪音計時而失敗（第一段）；
> 縮到逐對選門檻後，模型仍學不到有用的逐對差異（第二段，

**必須正面處理的張力**：若增益純粹來自「水準」，則 §4.2.3「替代解釋二」

## 五、仍然必須學會的統計

改題**不會把統計降到零**，但會把它降到兩個概念：

| 概念 | 為何非學不可 | 現有說明位置 |
| :--- | :--- | :--- |
| 循環 block bootstrap | 它產出主結果的 $p$ 與信賴區間 | §3.5.2（含為何不用 HAC、為何 $L$=126） |
| BH-FDR 校正 | 五個配對底是同一項檢定，必須一起校正 | §3.5.4 |

其餘存活下來的**全部是資訊本科概念**，不需另學：

- 置換檢定（三項替代解釋）＝ 隨機洗牌基準，本質是 Monte Carlo
- 五輪重訓變異 ＝ seed variance，ML 常識
- walk-forward ＝ train/test 切分
- 等權口徑 ＝ 避免 best-of-N 的選擇偏誤，等同不在測試集上調參

1. **主結果在門檻上很脆。** K-means 的 BH 校正後 $p$ = 0.0495 通過、

   被問「到底顯不顯著」時，正確答案是：
   *效果量 +0.239~+0.798pp、五個配對底有四個信賴區間下界為正；
   二分法不是這裡該用的框架。*
   這句話必須真的理解才講得出來。

2. **絕對績效不顯著、DSR 全數未過。** 論文的訊息是
   「相對於固定門檻有改善，但不足以交易」——有層次，不是
   「我做出一個會賺錢的策略」。第五章必須把這條界線畫清楚。

3. **機制證據與統計顯著兩份清單不重合。**
   三項機械性解釋全排除的是 GICS-SSD／HDBSCAN／GICS-SDP，

   **交集只有 HDBSCAN 與 GICS-SDP**。不可含混地說「GICS 兩底」。
